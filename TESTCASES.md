# TESTCASES.md

## API Test Cases

**Host:** `https://qa-internship.avito.com`  
**Version:** `v1`  
**Scope:** API микросервиса объявлений

### Эндпоинты в покрытии

- `POST /api/1/item` — создать объявление
- `GET /api/1/item/{id}` — получить объявление по id
- `GET /api/1/{sellerID}/item` — получить все объявления продавца
- `GET /api/1/statistic/{id}` — получить статистику по item id

### Применённые техники тест-дизайна

- классы эквивалентности;
- анализ граничных значений;
- негативное тестирование;
- E2E-потоки;
- контрактные проверки ответа;
- базовые нефункциональные проверки.

## TC-API-001 — Создание объявления с валидными данными
**Тип:** Positive  
**Приоритет:** High  
**Автоматизация:** Да

**Предусловия:** сервис доступен.

**Шаги:**
1. Отправить POST-запрос на `/api/1/item`.
2. Передать валидное тело запроса.

**Ожидаемый результат:**
- статус ответа `200 OK`;
- в ответе присутствует уникальный `id`;
- поля `sellerId`, `name`, `price`, `statistics` соответствуют телу запроса;
- поле `createdAt` заполнено.
